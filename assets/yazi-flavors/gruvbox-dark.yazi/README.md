# gruvbox-dark (dotmanager remix)

`flavor.toml` is a recolor of the official
[catppuccin-macchiato.yazi](https://github.com/yazi-rs/flavors/tree/main/catppuccin-macchiato.yazi)
flavor (same structure/table names, current with Yazi's schema) with
dotmanager's own Gruvbox Dark palette substituted in -- the standalone
[poperigby/gruvbox-dark-yazi](https://github.com/poperigby/gruvbox-dark-yazi)
flavor this was originally based on predates several tables Yazi now uses
(`[tabs]`, `[cmp]`, `[spot]`, `[notify]`, `[icon]`) and uses renamed keys
(`[manager]`/`[select]` instead of `[mgr]`/`[pick]`), so it only half-applies
on a current Yazi install.

`tmtheme.xml` (code-preview syntax highlighting) is unchanged from
poperigby/gruvbox-dark-yazi -- see LICENSE.
